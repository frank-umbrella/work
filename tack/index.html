Tack v0.1.0

Sticky notes that float on top of any website. Drag them, resize them, collapse them, pin them to a page, a site, or everywhere. They stay in your browser and can back up to your own Google Drive.

Install the userscript See the six styles

Install

  1. Install the Tampermonkey extension in the work Chrome profile (or Edge).
  2. Click Install the userscript above. Tampermonkey opens its install screen; confirm it.
  3. Open any site. A round button appears bottom-right. Click it for a new note, right-click it for the menu.

Updates arrive through Tampermonkey automatically. Tampermonkey needs "Allow access to file URLs" only if you want notes on local files.

Using it

New note

Click the launcher, press Alt+N, or use the Tampermonkey menu. New notes stick to the current site by default.

Move, size, collapse

Drag the header. Pull the bottom-right corner to resize. The dash button collapses a note to its header.

Pin scope

The triangle button switches a note between this page, this site, and everywhere. Page notes follow the exact URL.

Colors and styles

Six colors per note. Six note styles for everything, chosen in Settings: Post-it, OneNote, Glass, Umbrella, Slate, Paper.

Hide on a site

Right-click the launcher and choose "Hide notes on this site" when a site gets crowded. Notes are kept, just tucked away.

Export and import

Settings has Export JSON and Import JSON. Export before reinstalling Tampermonkey or moving to a new PC.

Google Drive backup (optional, one-time setup)

Tack talks to Google directly from your browser. There is no server in between, so it needs its own OAuth client in a Google Cloud project you control. The Client ID is a public identifier, not a secret. Do this signed in to the work Google account.

  1. Open Google Cloud Console, APIs & Services, Credentials. Create a project if there is none (any name, for example "Tack").
  2. Enable the Google Drive API under APIs & Services, Library.
  3. Under OAuth consent screen, choose Internal if the Workspace offers it (then only company accounts can sign in). Otherwise External, and add your own address as a test user. App name "Tack". No extra scopes need to be listed here.
  4. Back in Credentials, Create credentials, OAuth client ID, type Web application, name "Tack".
  5. Under Authorized JavaScript origins add https://frank-umbrella.github.io.
  6. Under Authorized redirect URIs add exactly https://frank-umbrella.github.io/work/tack/auth.html.
  7. Copy the Client ID (it ends in .apps.googleusercontent.com). On any site, right-click the Tack launcher, Settings, paste it under Google Drive backup, then click Connect Google Drive.

A popup asks you to pick the account and allow "See, edit, create, and delete only the specific Google Drive files you use with this app". That is the narrowest Drive permission Google offers; Tack can only see the one file it creates, tack-notes.json, in the root of My Drive.

How syncing works: the browser copy is always the source of truth. With auto-sync on, edits are pushed a few seconds after you stop typing, and a page load pulls once a minute at most. When the same note was changed in two places, the newer change wins. Deleted notes stay deleted on every device. Google sign-ins last about an hour; after that the launcher menu shows "reconnect" and one click brings it back.

Privacy

  • Notes are stored in Tampermonkey's storage on this PC. Nothing leaves the browser unless you connect Google Drive.
  • With Drive connected, the only network calls are to www.googleapis.com with your own token.
  • No analytics, no third-party scripts, no fonts loaded from the web.
